轻衡隐私政策

更新于 2026 年 10 月

轻衡不收集你的数据

轻衡没有账号，也没有自己的服务器。你记录的体重、运动和饮食只保存在你的手机上。卸载轻衡会删除这些记录。

AI 估算

只有在你配置了自己的 AI 服务并主动使用「拍照估算」时，你输入的文字和选择的照片才会从手机直接发送到你配置的服务（阿里云百炼或 DeepSeek）。这些内容如何处理，以该服务的隐私政策为准。照片只在估算时使用，不会保存在手机里。

API Key

你填写的 API Key 保存在 iOS 钥匙串中，只在你的手机上使用，不会被导出。

通知

只有你打开提醒时，轻衡才会请求通知权限。提醒由手机在本地安排，不经过任何服务器。

相机和相册

相机和相册只在你拍照估算时使用，用来选择一张食物照片。

导出和删除

你可以在「设置」里把全部记录导出为 CSV，或者一键清除全部记录。

健康提示

轻衡给出的热量是估算值，仅供参考，不构成医疗建议。
